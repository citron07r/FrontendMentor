# Frontend Mentor solutions

My solutions to [Frontend Mentor](https://www.frontendmentor.io) challenges. Each challenge lives in its own top-level folder with a self-contained `index.html` and local assets, and is published through GitHub Pages from the `main` branch.

## Running locally

No tooling or dependencies are required. Serve the repository root over HTTP and open a challenge folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000/summary-component/.
