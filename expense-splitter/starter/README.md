# Starter assets

These files ship with the Frontend Mentor challenge and are kept **unmodified**
for reference. Nothing here is loaded by the app.

The styles the app actually uses live at the project root:

| Live file | Purpose |
|-----------|---------|
| `../tokens.css` | design tokens (colour, type, spacing) |
| `../style.css` | components |

`tokens.css` in this folder is the starter's version, not the one in use.
`tailwind.css` is unused entirely — the solution is written in plain CSS.
